# 研习录生产流程 1.1（2026-11-05 定稿）

来历：2026-11-01 用暗黑 2 的资产排练出草案（design/studio/REHEARSAL.md）；2026-11-04 到 11-05 用自己的第一批资产（宋代营地一周小试：茅草偏屋九种组件、篝火、带路和草的地面、火焰）从出图一路走到手机上能开的引擎场景，按实际做法改定，去掉"草案"。每节标了**已实走**（营地小试真走过，有脚本、有数字）或**未实走**（只有设计，第一次用时再校）。数字和截图在 ASSET-SPEC 第 10 节，技术细节在 TECH-NOTES 卡十三到十九。

## 0. 六条原则

1. **一切是表。** 物件、房间、光、道具、物品、经济、声音、瓦片、角色九张表 + 预设与预制体；代码只读表。表有 Schema，`tools/tables_check.py` 进测试前置。营地小试新加的东西（地面分层、散布、灯的时段与闪烁、交互物件状态、人形碰撞、巡检目标）全部先进表或 Schema，再写代码。
2. **一件资产一个目录 + 一个定义 JSON。** `world/packs/<包>/<类>/<id>/`；同一包的贴图放 `packs/<包>/tex/` 共用（`tex_lo/` 半分辨率给手机档）。
3. **大东西是预制体，由组件拼。** 一栋房 = 墙段（含门窗洞变体）+ 柱 + 梁 + 屋面片与收头 + 屋脊 + 门扇；组件按模数在预制体里拼，改尺寸改模数不重出模型。
4. **光在表里，按时段。** 一盏主光 + 天光 + 局部灯 + 深度雾 + 后期，曝光全时段恒定，亮暗写在光量里；Blender 看光与引擎用同一套物理单位（营地，vis 的 `units: physical`）。
5. **会动的东西是状态机。** 物件有状态（门：半开 / 全开 / 关），寻路按"走近时的状态"算；火、灯按时段切态并闪烁。角色的状态机见第 4 节（未实走）。
6. **每一步都有尺子。** 出图量密度、组件量面数、拼好量接缝与净空、进引擎量明度与 draw call 与下载量；尺子是脚本，不靠目测。

## 2. 摆（预制体、预设、地面）

- 预制体在 `packs/<包>/prefabs/`，由 Blender 拼装场景导出，不手写；预设（`world/data/presets/<房>.json`）只放预制体、单件模型、地面、散布、特效、灯。已实走。
- 地面 = 两层平铺材质（土为底、草为第二层）+ 一张分层图（R 草、G 潮暗、B 路）；散布表与分层图同源同种子（草丛、石块、踏步石），引擎里同种一个实例网格。改种子整片重摇。已实走。
- 印章、贴花、摆放编辑器（放置 / 移动 / 旋转 / 变体重摇 / 拆包等动作）：未实走，M2 做编辑器最小版时校。

## 3. 光与后期

- vis 表每房每时段一条。实时光场景（营地）用物理单位：主光强度 = 太阳辐照度、天光强度 = 世界强度、灯写瓦数，与 Blender 看光同一套数；曝光恒定 0.33，夜晚的光量在表里调好，不靠调曝光。已实走。
- 烘焙场景（书房）沿用旧映射（主光 √功率、IBL^0.4）。
- 必须有环境遮蔽：实时场景用合成后期里的屏幕空间版（桌面 16 采样、手机 8 采样）；烘焙场景烘进贴图。
- 火、灯：程序化火焰（`world/render/fire.js`，定义在 `packs/<包>/vfx/`），灯可带 `flicker`；按时段切态（白天余烬冒烟、夜晚烧旺）。已实走。

## 4. 角色与交互（未实走）

- 动作一律原地播放（去根位移），移动速度由引擎按寻路实测。

## 8. 踩过的坑（排练 + 营地小试）

- 排练：软渲染下合成后期读不到多重采样深度图；夜晚远地需要 HDR 环境图；草地平铺要两层噪声 + 散布。
- 参考图会把同族组件拉向参考图里最像的那件；图像模型给不准洞口尺寸，洞口靠几何定、贴图按洞口拉伸。
- 三视图单视图只有 320 到 400 像素 / 米，当贴图会糊。
- .blend 存盘后贴图路径变相对，重读贴图要按绝对路径比。
- 网格没设活动颜色属性时，glTF 导出器写一组全白 COLOR_0、真数据在 COLOR_1（屋面旧化一度在引擎里没生效）。
- 同一张贴图从不同目录用相对路径引用，缓存认不出，会重复下载（营地一度 24 MB）。
- three 0.186 去掉了 PCFSoft 阴影；AgX 色调映射下火焰亮度超过 2 会压成粉白。
- 截图脚本每张重载页面会累积显存，第 7 张起 WebGL 上下文丢失；整轮只加载一次。
- 竖屏放宽视场角会变广角、露出地面尽头；改为镜头后退。
- 半开的门扇会把屋里堵成孤岛：寻路按交互物件"走近时的状态"算。
