# 研习录生产流程 1.0（草案，2026-11-01）

四阶段排练（design/studio/REHEARSAL.md）用暗黑 2 的资产把它的生产流程走了一遍，这页是走完以后写给自己的流程。**草案**：等用自己的第一批资产再走一遍，改掉不合身的，去掉"草案"二字。

## 0. 五条原则（排练里反复印证的）

1. **一切是表。** 物件、房间、光、道具、物品、经济、声音、瓦片、角色九张表 + 预设与预制体；代码只读表。表有 Schema，`tools/tables_check.py` 进测试前置。
2. **一件资产一个目录 + 一个定义 JSON。** 模型两档 LOD、贴图三件套（alb 1024 sRGB / nrm 1024 / orm 512，角色多一张 mask）、定义里记着色器、双面、透光、占地、碰撞、档位。
3. **大东西是预制体。** 帐篷 = 几十个实体打一包；城 = 预制体 + 零散 + 植被杂物散布 + 特效 + 音源。预制体里带自己的局部灯与地面印章。
4. **光在表里，按时段。** 一盏主光 + 环境图 + 深度雾 + 后期，曝光恒定，亮暗全在量里；角色另有一套灯；映射曲线固定（主光 √功率、环境光 IBL^0.4）。
5. **会动的东西是状态机 + 时间线。** 角色：一副骨架、部件按档换、状态 × 手持物绑动画、转移全连通带默认淡接；物件：停 → 播一遍 → 停三态；声音脚印特效都挂在时间线的时间点上。

## 1. 资产（一件东西怎么进来）

| 步 | 做什么 | 工具 | 检验 |

### 1.6 建筑与大件拆成组件（2026-11-04 加，来自 REFERENCES 的水上村落一条）

- 不整栋生成。一栋房 = 墙段（含门窗洞的变体）+ 柱 + 梁 + 屋顶片 + 屋脊 + 台基，像排练里帐篷 = 布 + 杆 + 板；组件按 ASSET-SPEC 的模数（墙段 2 米宽为主）对齐，预制体里拼。
- 改尺寸只改模数：门矮了就在预制体里把基准放大，不重出模型。
- 提示词写明**不要什么**：茅草 / 瓦 / 篱笆这类易镂空的，参考图与提示词里都写"厚实、无缝、从下看也完整"；墙写"有厚度"。
- 角色动作一律原地播放（去根位移），移动速度由引擎按寻路实测，避免滑步；背上挂件刚性绑骨。

### 1.7 贴图：独立还是图集（技术决定，2026-11-04，可逆）

- 先定**贴图密度**再定分辨率：同一包内按每米像素统一（目标 ≥ 500 像素 / 米，M1 画质门那条），30 厘米的木桩和 4 米的屋顶不分一样大的图。
- 1 档（手机）：同一预制体的组件合成一张图集（alb / nrm / orm 各一张），一个预制体一到两个材质；2 档以上：主角件（主屋、角色、商店物件）保留独立三件套，其余组件仍走图集。
- 图集由 asset_import 在登记预制体时打，不手拼。

## 2. 摆（预制体、预设、地面）

- 预制体文件在 `packs/<包>/prefabs/`，实体-组件，坐标相对原点；城 / 院子的预设只放预制体 + 零散。
- 地面三件：地面层（层编号网格 + 噪声混合）、印章（遮罩改层）、贴花（污渍压痕）；底层永远是土 / 路，草是第二层。
- 编辑器动作：放置 / 删除、移动（25 厘米吸附 + 自由）、旋转（15 度吸附 + 自由、三轴）、缩放、变体重摇、预制体整包放置与拆包、贴花、印章、散布、灯雾声实体、分档。
- 依赖清单由 tables_check 生成，不手写。

## 3. 光与后期

- vis 表每房每时段一条：主光（色、功率、俯角 47 固定、方位随时段）、IBL、深度雾（色、密度）、角色影深浅、角色 / 物品亮度系数、LUT、暗角。
- 渲染层：曝光恒定；主光 √功率 × k；环境图强度 IBL^0.4 × k；深度雾在材质里按距离；后期只管暗角颗粒 LUT。
- 环境图：先按时段生成的渐变（天 = 主光色为主），以后每时段烘一张立方图。
- 必须有环境遮蔽（烘进 ORM 红通道或屏幕空间），否则室内外一样亮。

## 4. 角色与交互

- characters 表：一副骨架 ≤ 80 骨、部件三档、14 个状态、6 类手持物、绑定规则 `<holdable>_<state>` 缺则回退、转移默认淡接 0.2 加例外、时间线事件五种。
- 物件 states：loop / crossfade / events，transitions any。
- 动画库独立目录，按角色一份；低档设备走壳状态机（neutral / walk / sit）。

## 5. 验收

- 每张图量：明度中位、5 到 95 分位跨度、死黑与过曝占比、饱和度、分区域光比；对照目标表（REHEARSAL 阶段三）。
- 预算：draw call、三角数、贴图总量按档位；tables_check 全过；回归截图四景别三时段。

## 6. 工具清单

已有：asset_import、asset_shrink、fal_image3d、tables_check、world_test、paint_verify、bake.sh、d2_decode（研究用）。
排练里写的、要转正的：prefab 组装（prepare / finish 的我们版）、场景看图页（scene.html → tools/tests/asset_view.py）、明度量尺（measure.py → tools/tests/measure.py）。
没有的：摆放编辑器、散布工具、环境图烘焙、状态机与时间线的播放器、人形巡检脚本（walk_check）、图集打包、镂空率量尺。

## 7. 排练留下的坑

软渲染下合成后期读不到多重采样深度图；噪声贴图是另一种压缩格式；动画曲线没解；帆布透光要有背面透光贴图；夜晚远地需要 HDR 环境图；草地平铺要两层噪声 + 散布。
